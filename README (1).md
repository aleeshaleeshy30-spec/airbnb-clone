# Airbnb Clone - Vacation Rental Platform

A fully functional Airbnb-inspired web application built as a complete frontend project.

![Airbnb Preview](https://picsum.photos/id/1015/1200/600)

## ✨ Features

- **Smart Search Bar** – Location, check-in & check-out dates
- **Beautiful Property Listings** – With images, ratings, and pricing
- **Interactive Booking System** – Modal with reservation confirmation
- **Wishlist Functionality** – Heart icon toggle
- **Fully Responsive** – Works on all devices
- **Modern UI** – Clean Airbnb-like design

## 🛠️ Technologies Used

- **HTML5**
- **Tailwind CSS** (via CDN)
- **Vanilla JavaScript**
- **Font Awesome Icons**
